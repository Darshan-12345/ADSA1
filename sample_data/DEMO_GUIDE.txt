10. FILE MANAGEMENT OPERATIONS
------------------------------------------------------------------------------

  - Change name → File renamed → Auto-rescan

Mark Important:

  - File gets important flag

Mark Temporary:
  - Right-click normal file → Mark as Temporary
  - Set TTL (e.g., 300 seconds = 5 minutes)
  - File appears in Temporary tab
